# 数学建模 UI 看板 — 安装说明

`dsh-math-modeling-ui` 是 **DSH 组合包**（`dsh.bundle.patch` + `dsh.client` 共存），通过 profile 安装后**持久生效，重启 DSH 自动加载，无需创造模式手动开启**。

## 安装步骤

1. **完全关闭 DSH Desktop**（profile 被占用时 pnpm 会报 EPERM）。
2. 打开 PowerShell，执行：

```powershell
# 设置 DSH_HOME 为桌面版 home（必须，否则会装到 ~/.dsh）
$env:DSH_HOME = "C:\Users\86198\AppData\Roaming\dsh-desktop\dsh-home"

# 安装（-w 必须，否则 pnpm 报 ERR_PNPM_ADDING_TO_ROOT）
dsh plugin --profile web add "C:\Users\86198\dsh-math-modeling-ui" -w
```

3. **重新打开 DSH Desktop**。

## 验证

- 设置 → 插件 → **数学建模** tab：出现进度看板开关（on/off，持久化）；
- 数学建模 Workbench 预设会话：右侧出现**折叠小条**（「📐 数学建模项目」+「展开」），点击展开三阶段 + 五门禁看板；
- 其他预设会话：右侧看板**不显示**（会话门控生效）。

## 前提

- **数学建模 agent 预设已装好**（`math-modeling-agent` 目录在 `$DSH_HOME/.agent-presets/`，含 `math-modeling.js`、`skills/`）；
- UI 看板只读 `<PROJECT_ROOT>/.math-modeling/state.json`（由 `mm_*` 工具写入），不依赖 math-modeling.js 内部状态。

## 备注

- 看板数据真相：`<PROJECT_ROOT>/.math-modeling/state.json`（跨会话、跨重启有效）；
- host RPC：`ctx.connection.rpc.handle('/math-modeling-ui', ...)`（组合包持久 RPC，`connection.rpc` 通道）；
- 会话门控：`ctx.sessions.list.getSnapshot()` 读当前会话 `agentPreset`，仅 `math-modeling-agent` 显示。
